## 🇬🇧 English

### 📖 About

**Nexo Store** is a modern e-commerce web application designed to give customers a smooth, fast and enjoyable shopping experience. It focuses on clean design, responsive layouts and simple navigation, so users can browse and find products easily on any device.

### ✨ Features

- 🛍️ Clean and intuitive product browsing
- 📱 Fully responsive design (mobile, tablet, desktop)
- ⚡ Fast loading and optimized performance
- 🎨 Modern and user-friendly interface
- 🌍 Arabic-friendly experience
- 🚀 Continuous deployment on Vercel

### 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/<your-repo>.git

# 2. Move into the project folder
cd <your-repo>

# 3. Install dependencies (if your project uses any)
npm install

# 4. Run the project locally
npm run dev
```

Then open `http://localhost:3000` in your browser (the port may differ depending on your setup).
